もぐめぐりBOOK ／ むかえる人のBOOK

チェックはこのスマホに保存されます。

  1. お店アプリの「📱 スタンプQR」番号を聞かれたら、主催者からの4桁を入力
  2. 印刷する → レジ・入口に貼るその場で見せるなら 大きく表示
  3. NFCタグ（使う場合）NFCタグ用URLをコピー → アプリ「NFC Tools」→ 書く → URL に貼り付け → タグにかざす
🗣 声かけ例：「もぐマップの 📷QRコードを読み取る で読んでくださいね」

お店アプリの「📮 お客様」に届きます（新着は数字が付きます）

  1. 📦 遠隔スタンプ購入の写真を見て スタンプを押す か 見送る
  2. 💬 メッセージ「お客様へ返信」に書いて 送る
  3. 📨 遠隔スタンプのURLを送る「📨 遠隔」→ URLとQRを作る → LINEで送る。お客様は開くだけでスタンプ（1人1回）
  4. 🔢 ID入力お客様の5桁IDを聞いて、その場でスタンプ
✉️ 「⚙️ 設定」でメール通知を登録すると見落とさない
🔴 「⚙️ 設定」→「アイコンに数字を出す」で、ホーム画面のアイコンに返事待ちの数が出ます（ホーム画面から開いたときに更新）

  1. ✏️ お店の情報紹介文・電話・購入ページ・SNSを直して 保存する（お客様アプリにすぐ反映）
  2. ✉️ メール通知メールアドレスを入れて 保存する → 確認メールが届いたら完了
  3. 🔴 アイコンに数字を出すホーム画面の「もぐマップ店」から開いて 数字を出す →「許可」
